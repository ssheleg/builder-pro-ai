# S-UXR Implementation Plan — UX-scenario base + testing loop + UI redesign

> REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Audit-first, then redesign. Each
> phase: run tasks → whole-branch review → ff-merge to main → CI green → next phase.

**Goal:** A maintained English UX-scenario base + a batched code-audit loop, then a token+primitives
UI redesign (direction A "Calm Control Room", light/dark, metrics-forward), shipped as `[0.9.0]`.

**Spec (contracts):** `docs/superpowers/specs/2026-07-18-s-uxr-redesign-scenario-base-design.md`.
All token values, primitive APIs, epic list, scenario/results formats, and the maintenance rule are
locked there — cite them, don't re-derive.

## Global constraints

- Branch `s-uxr` off main. English only (`scripts/check-english.sh` stays green; old RU catalogs in
  the allowlist). No wire verb / no schema change (pure frontend + docs + QA tooling).
- No new heavy deps (tokens = CSS vars; primitives = hand-rolled React; sparklines = inline SVG;
  icons only as inlined SVG under `src/ui/icons/`).
- PATH: `export PATH="$HOME/.cargo/bin:$HOME/.rustup/toolchains/1.92-aarch64-apple-darwin/bin:/opt/homebrew/bin:$PATH"`.
- Per redesign slice: behavior-preserving (same handlers/ipc/`data-testid`/`orchdDown` gating) →
  `npx vitest run` + `npx tsc --noEmit` + `scripts/check-english.sh` green → commit. Verify fmt via
  `... && echo CLEAN` (never pipe before `&&`).
