# S-POLISH Implementation Plan (P1..P5)

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development to
> implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax. Each phase is its own
> development branch: run its tasks, whole-branch review, merge, CI green, THEN start the next.

**Goal:** Bring v0.7.0 to a production-grade, fully-English first-session experience — close the
Critical + Important reliability gaps, expose UI-unreachable capabilities, add observability.

**Architecture:** Five sequenced slices ordered by coupling (backend → EN baseline → frontend
reliability → features → release). All cross-cutting contracts are LOCKED in the spec
`docs/superpowers/specs/2026-07-16-s-polish-program-design.md` (§4 D1–D8). Every task below
references those D-sections for exact signatures rather than re-deriving them.

**Tech stack:** Rust (bpa-orchd/sessiond/daemon-core, orchd-proto with ts-rs), React 19 + TS +
zustand webview, Tauri host. Tests: `cargo test` / `cargo nextest`, vitest + @testing-library.

## Global Constraints (every task inherits these)

- **Read the spec first.** `docs/superpowers/specs/2026-07-16-s-polish-program-design.md` locks
  D1 (strings.ts), D2 (no-cyrillic gate), D3 (storage_mode wire), D4 (tracing), D5 (timeouts),
  D6 (submit-guard/partial-failure), D7 (P4 features), D8 (reconnect/toast). Exact enum names,
  field names, verb names, and error mappings come from there VERBATIM.
- **Wire layering rule (frozen, append-only):** frame enums (`OrchdRequest`/`Response`/`Push`)
  are plain snake_case, NO ts-rs, NO `#[serde(rename_all)]`, new variants appended at END. ENTITY
  structs get `#[derive(...,ts_rs::TS)]` + `#[serde(rename_all="camelCase")]` +
  `#[ts(export_to="orchd-types.ts")]`, i64 fields `#[ts(type="number")]`. Mirror `McpArtifact`.
- **TDD:** failing test → confirm fail → minimal impl → confirm pass → commit. No step ships
  without a test asserting real behavior.
- **PATH:** `export PATH="$HOME/.cargo/bin:$HOME/.rustup/toolchains/1.92-aarch64-apple-darwin/bin:/opt/homebrew/bin:$PATH"`.
- **Secrets:** never log/serialize tokens, bearers, `client_secret`, args, bodies, tool output,
  PII. Extend the `no_secrets_in_logs*` tests when adding log lines.
- **English only** (once P2 lands): all new code/comments/copy/docs are English; the D2 gate
  enforces it — after P2 every phase must keep `scripts/check-english.sh` green.
- **RUST_TEST_THREADS=4** for the full suite (sessiond timing). Known BL-40 attach.rs PTY flake =
  retry-once. Stage sidecars `src-tauri/binaries/bpa-{sessiond,orchd}-aarch64-apple-darwin` for
  frontend/e2e gates.
- **Conventional commits**, trailer `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`.
- Per-phase closeout (not a task — the SDD controller does it): whole-branch review on the most
  capable model → `superpowers:finishing-a-development-branch` ff-merge to main → push → CI green.
