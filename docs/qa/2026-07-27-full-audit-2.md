## NEW findings (P1/P2) — BL-172..177

| ID | Sev | Area | Finding | File:line |
|----|-----|------|---------|-----------|
| **BL-172** | P1 | sessiond | **`kill()` joins the reader thread with no timeout.** An escaped (setsid'd) descendant holding the PTY slave keeps the reader's `read()` from EOFing; `killpg` SIGKILL can't reach a foreign-pgrp descendant, so `h.join()` blocks forever — wedges the KillSession task / `shutdown_all`, so SIGTERM never completes and the daemon needs `kill -9`. | `pty_supervisor.rs:759` |
| **BL-173** | P2 | orchd/mcp | **MCP HTTP transport follows redirects with the bearer attached.** `build_http_transport` uses rmcp's default reqwest (no explicit `redirect::Policy::none()`), unlike the OAuth token-exchange client which disables redirects for exactly this reason. A consented server issuing a 3xx can forward the bearer to a redirect target. | `crates/mcp/src/transport.rs:51` |
| **BL-174** | P2 | tauri/security | **Over-permissive entitlements.** `disable-library-validation` + `allow-dyld-environment-variables` are both `true` on the GUI (the IPC/Keychain control plane), enabling dylib injection at launch. The two non-WKWebView-required entitlements should be dropped (keep `allow-jit`/`allow-unsigned-executable-memory`). | `src-tauri/entitlements.plist:9` |
| **BL-175** | P2 | tauri/security | **`WorkspaceRootsCache` is not reset to `NeverLoaded` on `daemon://disconnected`.** Across a mid-session daemon bounce the fs-command root guard retains a stale `Loaded(map)` and can admit operations against roots the reconnected daemon no longer has (DB reset / workspace removed by another client). Fail-closed breaks across reconnect. | `src-tauri/src/commands.rs:260` |
| **BL-176** | P2 | orchd/graph | **Graph `add_node`/`move_node` accept non-finite `pos_x`/`pos_y`.** The DOM-3 `is_finite()` guard landed only on `set_task_rank` + import; the live wire verbs take `f64` verbatim. A stored NaN/±Inf makes the next `ExportAll` fail to serialize → un-backupable store (the exact DOM-3 class). Reachable via a crafted CBOR frame. | `crates/orchd/src/graph.rs:360,491` |
| **BL-177** | P2 | release | **`release.yml` `cp "${tgz}.sig"` is unconditional inside `set -euo pipefail`.** When `TAURI_SIGNING_PRIVATE_KEY` is absent the `.sig` isn't produced, so the build dies hard — contradicting the documented "degrades honestly to dev-signed (loud warning, not a failure)" contract. | `.github/workflows/release.yml:130` |
