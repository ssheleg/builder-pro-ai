### Screen: Stats view (FLW-20, SCN-052/053)
- **Purpose:** honest usage/output read for a chosen range
- **Elements:** SegmentedPill (All|30d|7d), stat tiles, Heatmap, per-project table, per-model-family cut (new), freshness stamp, error notes **with attached Retry**, **Cancel affordance while scanning**
- **States:**
  - loading → "Scanning usage…" + Cancel button; tiles show "—" skeletons, never zeros
  - empty → EmptyState only when BOTH sources empty for the range
  - error → per-source note + Retry attached to the note; usage-derived tiles show "—" while `usageError` set, git figures stay numeric; git worker failure surfaces as `gitError` (no `unwrap_or_default` fake-empty)
  - success → figures provably belong to the selected range (epoch guard); stamp reflects the completed refresh, present even when one source failed
- **Behavior notes:** request-epoch token in the stats slice: every `refreshStats` increments it, replies carrying a stale epoch are discarded; Cancel bumps the epoch and clears `loading`; range pill/Refresh either gated or queued while in flight; heatmap windows by the selected range (or is labeled as fixed-30d independent of the pill — pick one, say it in UI)

### Screen: Rules tab — supervisor section (FLW-19 config half, SCN-046)

- **Elements:** inherited-caps summary gains the effective trust-policy `ratePerMin` (exists at orchd-types.ts:196, currently unsurfaced)
- **Behavior notes:** if product decision goes the other way, amend SCN-046 step 2 to spend-only instead — one of the two must land (doc/code mismatch cannot persist)

### Screen: Rules tab + Docs tab — dirty-draft guard (SCN-036/046/054)

- **Behavior notes:** store-wins hydration (RulesetPanel.tsx:431-446, DocsPanel.tsx:300-304) skips resetting fields whose draft ≠ last-hydrated value; the existing external-change banner mediates the conflict
